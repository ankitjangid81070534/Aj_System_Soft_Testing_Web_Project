## Cannibalization and scope rules

1. Homepage owns the brand; `/services` helps choose a category; a specialist service URL owns its provider/buyer query. Do not repeat the same commercial primary on all three.
2. The custom-software page covers requirements-first bespoke delivery. ERP, industry systems, SaaS and platform services keep their narrower capability intent.
3. Articles own how/why/comparison questions; service pages own provider selection and enquiries. Link between them instead of creating near-identical commercial and informational pages for each phrase.
4. Retail POS covers counter/stock operations; ERP covers cross-department workflow; pharmacy adds batch/expiry and medical-stock needs; hospital covers patient/department operations. Shared billing terms do not justify duplicate pages.
5. Web application vs website vs mobile should follow real use cases. Do not create separate city, spelling, script, device-model or price-variation doorway pages.
6. A template-generated cost, security or testing question does not prove an answer, fixed price, certification, compliance guarantee or capability beyond the cited feature. Validate it with the owner; omit claims that cannot be substantiated.
7. Do not target `/ajadmin`, `/account`, auth/reset routes, `/design-preview`, API endpoints, nonexistent offer/update pages, or private client records. No new service category is established by the research.

- After publication and authorization, use a real Search Console Performance export (query + landing page, country, device, date range, impressions, clicks, CTR, position). Keep observed queries separate from these inferred candidates and deduplicate within comparable date ranges; do not label absent rows zero-demand.
- Classify observed intent, compare the currently ranking landing page with this owner map, and inspect competing results before assigning priority. Use actual data to replace equal quotas, not invented volume/KD values.
- Select a small useful primary/secondary set; improve answers and links naturally. Do not paste the CSV into copy, meta keywords, hidden blocks or thousands of pages. Do not interpret 5,000 rows as 5,000 content briefs.
- Review cannibalization and actual enquiry quality after changes. Never claim guaranteed ranking or manufacture impressions, clicks, reviews, clients, prices or proof.
